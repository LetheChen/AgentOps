## 使用建议

* **README 配图**：每张图引用相对路径 `docs/gallery/<name>.png`，GitHub 自动渲染

* **培训分享 PPT**：可直接插入

* **二次传播**：保留文件名前缀（中文）便于目录浏览；如需英文版可补 `*-en.png` 副本
