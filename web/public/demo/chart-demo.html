AgentOps 生成式 UI 演示面板 Chart.js

此面板用于在 widget 渲染链路（HtmlWidget iframe sandbox 禁用 JS）不可用时，
以独立 HTML 形式展示 Manager Agent 可产出的可视化数据。浏览器直接打开即可查看，无需后端。
📈 Token 用量趋势（近 7 天）
input_tokens / output_tokens 双折线，对应 WidgetRenderer 的 chart widget (chart_type=line)
📊 Provider Token 分布
各 provider 的总 token 占比，对应 chart widget (chart_type=bar)
🥧 Run Mode 分布
templated / conversational / hybrid / task 占比
🔍 原始数据（Manager Agent emit_widget 应产出的结构）
对应 emit_widget 工具的 data 负载，前端 WidgetRenderer.ChartWidget 应消费此结构渲染

    

  


  

    访问方式：
    1) 直接 file:// 打开本文件；2) 通过 vite dev server 访问 http://localhost:5173/demo/chart-demo.html
