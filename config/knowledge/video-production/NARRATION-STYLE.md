# 搜索数据 → 口播稿风格指南

把搜索数据/文章转成"说出来不别扭"的口播稿。默认 **B站风格**。

> **两条底线**（任一不过，整稿重写）：
>
> 1. **信息保留度 ≥ 60%** —— 口播稿是"换说法"，不是"摘要"。删冗余/修饰可以，删事实/数据/案例/论证链不行。
> 2. **去AI味** —— 即使句子已经短句化、口语化、第二人称，AI的腔调（假共情/假深刻/自我标榜/万能模板/排比堆砌）念出来仍然一耳朵是机器。**口播比文字更怕AI味**。
>
> 8条原则讲**形式**，「去AI味五类」讲**风骨**。两者都建立在「信息保留度」这一最高约束之上。

---

## 最高原则：信息保留度 ≥ 60%

> 这条**优先于**下面所有8条原则和去AI味五类。先保证信息没丢，再调形式/风骨。

**判定标准**：
- `len(narration.md) ÷ len(search-results.md) ≥ 0.6`
- 关键事实（数字/名称/时间/论断）**逐项对得上**，不能整段消失
- 数据里的**论证链**（前提→结论/因果/对比）必须保留，可以换说法但不能跳步

**允许压缩的**：套话开场/重复总结/客套结语。
**禁止压缩的**：关键数据和数字、具体案例/故事、多步论证里的中间步骤、反方观点/限制条件。

## B站风格的8条原则（形式层面）

### 1. 口语化：所有书面语换成"说出来不会别扭"的句子

| 书面语 | 口播 |
|--------|------|
| 综上所述 | 所以你看 |
| 具有非凡的意义 | 这件事真的挺重要 |
| 在……方面有显著提升 | 在……上明显变强了 |
| 该工具旨在 | 这玩意是用来 |
| 笔者认为 | 我觉得 |
| 由此可见 | 你看吧 / 这就是为啥 |
| 与之相反 | 反过来 |
| 据相关资料显示 | 我查了下 |

判断标准：**把它念出来，会不会觉得"这人怎么这么端着"**？会就改。

### 2. 短句：每句 ≤ 20 字

长句拆短句，逗号优先于复合句。

| 原文 | 改写 |
|------|------|
| "尽管它在文字渲染方面有了显著的提升，但在某些复杂场景下仍然会出现错误。" | "文字渲染确实变强了。但复杂场景下，它还是会翻车。" |
| "我们通过对比测试发现该模型在指令遵循能力上明显优于上一代。" | "我做了一组对比测试。指令遵循这一项，比上一代强太多了。" |

### 3. 第二人称：多用"你/我们"，少用"用户/读者"

| 原文 | 改写 |
|------|------|
| 用户可以通过该接口实现 | 你只要调一下这个接口 |
| 读者将会发现 | 你会发现 |
| 开发者需要注意 | 你写的时候要小心 |

### 4. 开头有钩子（cold open）

第一句必须**抓住人**。三种通用钩子：

- **悬念**："这是真的吗？" / "你猜怎么着" / "我以为是bug，结果……"
- **反差**："这玩意以前要3小时，现在30秒。" / "上周还人人吹爆，今天就翻车了。"
- **利益**："看完这条，你就能省下买插件的钱。"

**禁止**：
- ❌ "大家好今天我们来讲讲" 自我介绍开场
- ❌ "本期视频我们将探讨" PPT标题感
- ❌ "在开始之前，让我们先了解一下背景" 铺垫
- ❌ "我知道你最近肯定很纠结X" 假共情钩子
- ❌ "接下来我说的，可能会颠覆你的认知" 自我加权钩子

### 5. 节奏停顿：用 `---` 分隔每个完整想法

每讲完一个聚焦的想法 = 一个 step 边界 = 一个 `---`。

```markdown
所以呢，这玩意儿真的挺夸张的。

---

举个例子。前几天我让它画一张海报，三秒就出。

---

但你知道最离谱的是啥吗？连里面的中文字都对了。
```

### 6. 数字翻译成感受

观众听到具体百分比和大数字会**走神**。除非数字本身就是核心冲击点。

| 原文 | 改写 |
|------|------|
| 准确率提升了47% | 几乎快了一倍 |
| 覆盖120个国家/地区 | 全世界基本到处都用 |
| 用户数突破1.2亿 | 现在已经是国民级应用了 |

例外：**核心冲击数字**保留并强调（"前后差了100倍"、"3秒 vs 3小时"）。

### 7. 不堆结构词/不堆万能模板

**禁止**：❌ "首先/其次/最后" ❌ "总结一下，本期视频我们讲了什么"
❌ "说白了……" / "本质上……" / "底层逻辑是……"

**做法**：把这些词融进自然过渡，或者直接砍掉。
- "首先，文字渲染" → "先说文字渲染"
- "总结一下" → "所以你看"

### 8. 具体例子优先

**抽象**会让人走神，**具体**会让人坐住。

| 抽象 | 具体 |
|------|------|
| 它有很强的能力 | 你给它一张猫的照片，让它换成赛博朋克风，3秒就出 |
| 性能优越 | 我那台5年前的旧电脑跑得动 |
| 应用场景广泛 | 海报、PPT、表情包都能整 |

**举例规则：从"我"出发**。"我做了一个测试"、"我让它画"比"用户可以"亲切100倍。

## 去AI味：五类必清的腔调（风骨层面）

> 唯一判断标准：**这话念出来，一个真人会这么说吗**？不会就改。

### 一、假共情：开口就演"我懂你"

❌ "我知道你最近肯定很纠结X" / "你是不是也有这种感觉" / "你的感受是被看见的"
✓ 直接抛事实/钩子。亲不亲是观众听完判断的，不是你一开口就宣布的。

### 二、假深刻：用"恰恰/反而/正是"包装平庸观点

❌ "你以为它强是因为模型大，恰恰相反……" / "这反而是它真正可怕的地方"
✓ 去掉转折包装直接说结论。**自检**："恰恰"那句去掉后意思变了吗？没变就删。

### 三、自我标榜：说正事前先给自己加权

❌ "我必须很认真地说一句" / "接下来我说的，可能会颠覆你的认知" / "这一段你一定要听完"
✓ **直接说**。好观点不需要预热。

### 四、万能模板：一听就是AI写的口头禅

| 位置 | ❌ AI模板 | ✓ 口播版 |
|------|----------|----------|
| 开头 | "说白了……" / "本质上……" | 直接说"它就是X" |
| 过渡 | "一句话总结……" / "换句话说……" | 直接说那句话，不预告 |
| 包装 | "在某种意义上" / "从某种程度上来讲" | 删掉，没意义 |
| 结尾 | "以上就是本期内容" / "希望对你有帮助" | 具体CTA："链接评论区置顶" |
| 互动 | "你想让我继续讲X吗？" | 给具体动作："去GitHub搜X" |

### 五、排比堆砌：连续三句结构一样

❌ "不躲，不藏，不绕，不逃" / "高效，精准，强大"
✓ 保留最有信息量的一两个，其余砍掉；或换成一个具体例子。

## 几个**不要做**的细节

- ❌ **emoji**：口播稿里不要emoji，那是文字弹幕，不是讲话
- ❌ **括号补充**："这个模型（一种基于transformer的架构）很厉害" → 念不出来
- ❌ **罗列书名号/引号**："《XX报告》指出" → 改成"我看到一份报告说"
- ❌ **"哈哈哈"等口头语堆砌**
- ❌ **过度网络梗**：有半年保鲜期

## 平台风格变体

如果用户指定了别的平台，按下表调：

| 平台 | 风格基调 | 单句长度 | 钩子节奏 | 信息密度 |
|------|---------|---------|---------|---------|
| **B站**（默认） | 自来熟、有段子、节奏快 | ≤20字 | 3秒钩子 | 中（5秒/idea） |
| **抖音/视频号** | 更燃、更短、更冲击 | ≤12字 | 1秒钩子 | 高（3秒/idea） |
| **YouTube long** | 舒缓、详细、可铺垫 | ≤30字 | 30秒铺垫可 | 低（10秒/idea） |
| **知乎视频** | 严谨一点、有逻辑感 | ≤25字 | 5秒铺背景 | 中（5-7秒/idea） |
| **小红书** | 闺蜜分享感、有情绪 | ≤15字 | 直接讲结论 | 中（5秒/idea） |

## 主题类型微调

- **技术/教程**：可以稍"端着"，但仍口语化。多用"我们试一下"
- **测评/对比**：要"敢说"。"这个不行"、"那个吹过头了"。**敢说≠自我标榜**
- **新闻/资讯**：节奏要快，金句要硬。开头第一句给最炸的点
- **产品/营销**：忌"吹"。不说"完美"、"颠覆"，说"我用了一周，确实顺手"
- **文化/历史/科普**：放慢节奏，多用"你想象一下"开场

## 念出来测试（终极标准）

随便挑3段念出来 —— 不要在心里默读，**真的张嘴念**。

- 念到哪句你觉得"这话我说不出口" → 那句是AI味
- 念到哪句你想跳过 → 那段是排比/自我标榜
- 念到哪句你想笑出声（不是因为内容好笑，是因为油腻）→ 那句是假共情

**改完再念。直到三段念下来都自然为止**。
