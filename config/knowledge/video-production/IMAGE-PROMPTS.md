# 图像生成提示词指南

**每条图像 prompt 必须按结构化骨架构建，禁止只写一句话描述。**

---

## 六维 Prompt 骨架

```
主体（Subject）→ 场景（Scene）→ 布局（Layout）→ 风格（Style）→ 细节（Details）→ 约束（Constraints）
```

| 维度 | 职责 | 示例 |
|------|------|------|
| **Subject** | 画面主体是什么 | 人物/商品/城市/角色/数据仪表盘 |
| **Scene** | 场景/背景/环境/氛围 | 深色影棚/明亮办公室/手绘地图/终端界面 |
| **Layout** | 画面区域组织方式 | 左文右图/三栏卡片/中心hero+环绕数据/全屏图+底部文字 |
| **Style** | 风格/渲染/材质/色彩/光线 | 电影感/插画风/学术白底/杂志编辑级/技术暗色grid |
| **Details** | 局部细节 | 卖点标注/callout标注/图例/引用文字/右下角来源角标 |
| **Constraints** | 必须出现/必须避免 | 禁止假数据/禁止emoji/文字必须可读/风格与全局一致 |

---

## 参数分类策略

每个 prompt 字段判断属于哪一类：

| 分类 | 策略 | 示例 |
|------|------|------|
| **核心参数** | 缺失影响结果，优先问用户 | 主体是谁、商品名称、城市名 |
| **可默认参数** | 可先用默认值 | 背景色、次级文案、常规灯光 |
| **可随机参数** | 允许自动补全 | 路人昵称、小装饰元素、次级背景 |

## 场景类型与 Prompt 模板

### 1. 开场/封面 — 品牌主张 + 大文字

```
类型：品牌主视觉海报
目标：视频封面/开场画面
主体：{主题核心元素，如"GitHub开源项目"}
场景：深色背景+舞台聚光
布局：中心hero大标题+顶部logo+底部副标题slogan
风格：电影感编辑级/杂志封面感，{深色/暗金/科技蓝 择一}
细节：标题文字 "{项目名/主题}"，副标题 "{一句话主张}"
约束：文字占画面≥40%/须清晰可读/不含emoji/不要假数据
```

### 2. 数据展示 — KPI仪表盘

```
类型：信息图仪表盘
目标：展示核心数据指标
主体：{N个关键指标，如Star数/增长率/排名}
场景：{深色/浅色} 简约信息图底板
布局：2×2 或 1×3 卡片网格，每卡片=一个指标
风格：现代简约/技术感，{深蓝+白/暗黑+青绿}
细节：每卡片含大号数字+小号标签+微量趋势箭头/迷你柱条
约束：数字真实（来自search-results.md）/字体清晰/≥24px/无假数据/无emoji
```

### 3. 对比/测评 — A vs B 对比

```
类型：对比信息图
目标：展示{主体A} vs {主体B} 的多维对比
主体：{两方名称}
场景：中性灰色底 或 左右分色底
布局：垂直或水平分栏，中央VS分隔线
风格：现代对比图，{深色+对比色 或 浅色+分割线}
细节：3-5个对比维度（每维度行标题+双方数值+胜负高亮）
约束：数值准确/对比维度有实际意义/无假数据/无装饰性emoji
```

### 4. 步骤讲解 — 插画感教程

```
类型：步骤教程信息图
目标：展示{N}步操作流程
主体：{流程主题}
场景：温暖明亮的工作台/桌面氛围
布局：垂直或Z字形步骤排列，编号+小插图+文字
风格：温暖插画感/柔和配色，{暖橙+奶油/薄荷绿+白}
细节：每步编号（Step 1/N）+ 一句描述 + 小图标/插画
约束：步骤≤6步/文字清晰/插画风格一致/不要照片写实
```

### 5. 产品展示 — 高级影棚

```
类型：高级影棚产品图
目标：展示产品 {产品名/项目logo或界面截图}
主体：{产品描述}
场景：影棚暗色环境+单侧柔光+焦外光斑
布局：主体居中偏左/偏右，大面积留白放文字叠加
风格：杂志广告级质感，{哑光黑+金属银 或 暖木+奶油}
细节：产品质感（玻璃/金属/磨砂），焦外散景，品牌光泽
约束：图片留白≥30%/风格与视频整体一致/画面干净不杂
```

## 通用 Prompt 结构模板（可复用）

如果上面的特定模板都不匹配，使用通用骨架：

```
类型：{画面类型，信息图/海报/场景/界面/产品图}
目标：这张图在视频中的用途——{开场吸引/数据证明/步骤演示/对比展示/情感渲染}
主体：{画面核心内容/人物/对象}
场景：{环境/背景/氛围描述}
布局：{构图方式，文字位置/主体位置/留白区域}
风格：{视觉风格/色调/质感}。整体调性与视频主题{主题风格}保持一致。
细节：{关键标注/数字/引用/角标}
约束：必须{保留什么}。禁止{假数据/emoji/紫粉渐变/与其他场景风格割裂}。
```

## 视频场景 → 推荐模板速查

| 视频场景 | 推荐模板关键词 | 核心要点 |
|---------|--------------|---------|
| 开场钩子 | 品牌主视觉/海报 | 大文字占画面40%+，冲击力强 |
| hero数据 | KPI仪表盘 | 数字大+标签小+无假数据 |
| 对比分析 | A vs B 对比图 | 中央VS线+高亮胜负 |
| 流程步骤 | 步骤教程图 | 编号清晰+风格一致 |
| 产品展示 | 高级影棚/白色背景 | 大面积留白+质感突出 |
| 技术架构 | 系统架构图 | 暗色grid+角色编码配色 |
| 城市/地域 | 手绘地图 | 地标+路径+图例 |
| 情感渲染 | 概念场景 | 氛围>信息，留白>填充 |
| 结尾CTA | 品牌海报变体 | 简洁有力+行动引导 |

## Prompt 落盘规则

每张图生成后，其 prompt 必须保存到 `media/prompts/scene-NN.md`：

```markdown
# Scene NN Prompt
- 生成时间：{timestamp}
- 目标场景：{场景标题}
- 对应 storyboard：scene-NN

## 最终 Prompt
{渲染好的完整prompt文本}
```

**目的**：追溯问题、复用调整、风格一致性检查。
