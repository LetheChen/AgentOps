# 去 AI 味写作样例（好 vs 差）

> 本页面记录周报条目「好表达」vs「差表达」对比，供 weekly_report agent 提炼时参考。
> 配合 [template.md](../template.md) 的「agent 提炼规则铁律 v2」使用。

## 核心原则

> **去 AI 味 = 动作 + 对象 + 量化结果**
>
> AI 味条目典型特征：
> - 抽象动词（推进 / 优化 / 提升 / 改善 / 强化）
> - 缺对象（不知道动了什么）
> - 缺结果（不知道影响多大）
> - 套话前缀（积极 / 全力 / 持续 / 有效）
>
> 好的条目必须有「具体动作 + 具体对象 + 量化结果」三要素。

## 专有名词保留规则

### 保留原样（不翻译不简化）

- 系统名：审批中心 / 智能审核 / 合同台账 / ERP / OA / CRM / BI / EHR
- 数据库 / 表 / 字段：`t_approval_log` / `user_id` / `biz_report`
- 接口 / 工单：`/api/knowledge/ask` / `OPS-2026-0421` / `JIRA-12345`
- 项目代号：`YH-CPKF-2025122` / `HFXZ-2026-Q2`
- 量化单位：万行 / GB / QPS / P95 / RPS / 卷

### ❌ 错误简化

- ❌ "审批系统" → ✅ "审批中心"（保持项目内部命名）
- ❌ "智能算法模型工厂" → ✅ "智能视频算法模型工厂"（不能省略"视频"）
- ❌ "赵六的 OA 账号" → ✅ "丁静 / 颜浩然 OA 账号"（保留具体人名）

### C 级合并优秀样例（W31 · 12 → 1）

#### ✅ 本周合并执行（推荐样例）

`
### 一、系统功能优化及新增（共 1 项）

#### [C] 合并汇总项
- **[C] 另处理 12 项简单咨询 / 单点操作**（覆盖：单点权限开通、配置校验、流程节点确认等无需专人专项闭环的工作）[#src:6][#src:7][#src:9][#src:11][#src:12][#src:18][#src:23][#src:24][#src:27][#src:29][#src:31][#src:35]
`

**要点**：
- 12 个 #src:N 标记合并为 1 行（保留溯源能力）
- 覆盖范围说明在括号内（避免丢信息）
- 维度归属清晰（挂在维度一末尾）

- item_count = 25 校验通过
